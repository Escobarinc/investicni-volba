# Investiční volba

Dvě landing page, kde návštěvník za kontakt získá PDF průvodce:

- `reality-bez-koupe/` – 5A Reality bez koupě nemovitosti
- `byt-vs-dluhopis/` – 5B Investiční byt, nebo developerský dluhopis?

Společné soubory: `styles.css`, `script.js`, `assets/` (fotky a PDF). Formulář posílá kontakt do CRM přes `window.clarixTrack.lead`, jakmile bude na stránce měřicí skript CLARIX. Do té doby kontakt nikam neodchází a zobrazí se jen odkaz ke stažení PDF.
